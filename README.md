# MASTERSHINA — демо главной страницы «PRIME»

Демо-вариант дизайна главной страницы интернет-каталога [MASTERSHINA](https://mastershina.uz/) — шины, диски и запчасти для грузовиков и спецтехники с заготовкой под онлайн-оплату (эквайринг).

**Смотреть:** https://alex22826.github.io/mastershina-demo-prime/
Другие варианты: [TURBO](https://alex22826.github.io/mastershina-demo-turbo/), [CANDY](https://alex22826.github.io/mastershina-demo-candy/)

## Стиль

Премиальный стиль: тёмно-синий + электрический градиент, стекло (glassmorphism), крупная типографика Unbounded.

## Что внутри

- Hero с анимацией заголовка по строкам, стеклянным поиском по размеру и карточкой хита
- Скролл-история «Четыре направления»: шина вращается при прокрутке, меняются товары
- Полноценный каталог: фильтры (категория, бренд, диаметр, цена), сортировка, плитка/список, быстрый просмотр
- Поиск-палитра по Ctrl+K, курсор-кольцо, превью услуг за курсором
- 3D-карта оплаты, таймлайн компании, слайдер отзывов, оптовый CTA, шоурумы с картой
- Корзина, оформление заказа и выбор оплаты: Payme, Click, Uzum, UzCard / HUMO / Visa, оплата при получении
- Обратный звонок, маска телефона +998, адаптив под телефоны и планшеты

## Структура

```
index.html            — разметка главной
assets/css/style.css  — стили варианта
assets/js/data.js     — каталог, контакты, отзывы (демо-данные)
assets/js/core.js     — корзина, оформление заказа, оплата, анимации появления
assets/js/main.js     — логика этого варианта (слайдеры, подбор, фильтры)
assets/img/           — фото товаров, компании и баннеров
```

## Запуск локально

Сайт статический, сборка не нужна:

```bash
python -m http.server 8000
```

и открыть http://localhost:8000

## Эквайринг

Точка интеграции — функция `startPayment(order)` в `assets/js/core.js`. Сейчас это имитация: в рабочей версии она должна обращаться к backend, который создаёт счёт в Payme / Click / Uzum и возвращает ссылку на платёжную страницу. Данные карт на сайте не вводятся и не хранятся.

## Что заменить перед запуском

- Цены, остатки и рейтинги в `data.js` — демонстрационные (в будущем — из 1С/API)
- Отзывы — примеры, заменить на реальные
- Цифры в блоке «О компании» (кроме года основания) — уточнить у клиента
